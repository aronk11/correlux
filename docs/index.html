DOCS / DOCUMENTATION

The friendly manual

Welcome to Correlux. Less cluster, more clarity — and documentation you can actually read during an incident.

Start here

Getting started covers installation on macOS, Linux and Windows, cluster access, a first incident walkthrough and troubleshooting.

Already installed? Open the user guide for the complete set of workflows, keyboard shortcuts and configuration options.

Find your workflow

  • Air-gapped operation: offline installation, registry mirrors, image defaults and upgrades.
  • Applications and health: how Correlux connects workloads, pods and networking.
  • The WHY engine: deterministic findings, attributed evidence and confidence.
  • Logs: multiple containers, following and previous runs.
  • Resource usage: reservations, live metrics and placement.
  • Fleet groups: selected clusters, read-only triage and cross-cluster resource tables.
  • Safe changes: scale, edit and production confirmation.
  • Helm, Flux and Argo CD: Helm operations, Flux reconciliation and delivery metadata.
  • Troubleshooting sessions: approved toolbox/probe images, ephemeral containers and pod port-forwards.
  • Connected investigations: routing, storage, references, fleet comparisons and local snapshots.
  • Configuration: themes, startup, refresh, safety and keybindings.
  • Accessibility: keyboard navigation, ASCII fallback and colour controls.

Understand the design

The architecture explains how data travels from kubeconfig to the terminal. The architecture decision records explain why the system is built this way: evidence on demand, session-local context switching, server-rendered resource tables and a shared confirmation gate.

The product specification records the intended direction. Consult the roadmap and release notes to distinguish available functionality from planned work.

Build with us

The contribution guide covers local development, checks and testing against kind. Read the code of conduct and security policy before contributing or reporting a vulnerability.

Search without leaving your flow

Use Search docs or press Ctrl+K (⌘K on macOS) to search the user guide, setup instructions, architecture and decisions. Search happens in your browser; no account or search service is involved.

These pages are built from the repository’s Markdown documents. Fixing a guide in the repository updates the website on its next deployment.
